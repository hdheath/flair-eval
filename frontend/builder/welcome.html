Compare FLAIR runs side by side

flair-eval runs several FLAIR versions, branches or settings on the same long-read data and puts the results in one report: isoform categories against your annotation, junction novelty, length distributions, and what changed between runs.

Set up a comparison See a demo report GitHub

Get started

  1. Install

    Nextflow (with Java 17+) runs the pipeline. The flair-eval helper checks your machine and writes the config files.

    conda create -y -n nextflow -c conda-forge -c bioconda nextflow openjdk=17
conda activate nextflow
    pip install "flair-eval @ git+https://github.com/hdheath/flair-eval@v2#subdirectory=cli"
flair-eval doctor

  2. Try the test data

    A small run on bundled test data shows the whole thing working before you point it at your own files.

    flair-eval run --test --outdir /private/groups/brookslab/$USER/flair-eval/dd_mm_yy_test

    On phoenix (UCSC PRISM) this submits the Nextflow driver as a SLURM job and prints its job id and log. The report lands in <outdir>/report/report.html. --outdir is always required: use groups or warm-archive storage, not your home folder.

  3. Describe your data

    Fill in the config builder and copy its command, or answer a few questions in the terminal:

    flair-eval init
flair-eval run --outdir /private/groups/brookslab/$USER/flair-eval/dd_mm_yy_name

No files needed for a quick look

One sample against three FLAIR builds, in one command. Each --flair token becomes a run. On phoenix no -profile is needed and --genome hg38 picks the lab reference (GRCh38 + GENCODE v49 basic), so --gtf can be left out. flair-eval run takes the same flags and submits the Nextflow driver as a SLURM job.

flair-eval run --reads sample.fq.gz --genome hg38 \
  --flair 2.2.0,3.0.1,dev --outdir /private/groups/brookslab/$USER/flair-eval/dd_mm_yy_name

The same with Nextflow directly (inside an sbatch job on phoenix; add -profile local,conda elsewhere):

nextflow run hdheath/flair-eval -r v2 \
  --reads sample.fq.gz --genome hg38 \
  --flair 2.2.0,3.0.1,dev --outdir /private/groups/brookslab/$USER/flair-eval/dd_mm_yy_name
